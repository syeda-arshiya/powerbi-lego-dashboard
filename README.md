# LEGO Set Finder - Power BI Dashboard

## Overview

This project is an interactive Power BI dashboard developed to analyze LEGO set data and provide insights into LEGO themes, pricing, piece counts, and product trends.

The dashboard allows users to explore LEGO sets through interactive visuals, filters, and KPIs to identify patterns across different categories.

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Dashboard Features

- Total LEGO sets analysis
- Average number of pieces per set
- Price analysis
- Theme-wise performance
- Interactive slicers and filters
- Drill-down analysis

## Key Skills Demonstrated

- Data cleaning and transformation using Power Query
- Creating relationships between tables
- Developing DAX measures
- Designing interactive dashboards
- Data storytelling and visualization
